# AlgoLab · 算法对比实验室

[打开网站](https://1368010020.github.io/algo-lab/)

纯前端中文算法学习网站，手机和电脑均可使用。

- 六种排序：冒泡、快速、插入、选择、归并、堆排序；支持相同输入双栏对比。
- 查找：线性查找与二分查找，支持命中、未命中和有序输入校验。
- 图遍历：BFS 与 DFS，可编辑障碍、起点和终点，显示路径与访问节点。
- 所有实验支持播放、暂停、调速、单步、回退和时间轴。
- 算法原理、JavaScript 示例、复杂度与计数口径说明。
- 学习标记保存于当前浏览器的 localStorage，不跨设备同步。

## 本地预览

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 http://localhost:8765/。无需 npm、后端或数据库。

## 发布

GitHub Pages 使用 main 分支根目录，每次推送自动部署。

动画操作数不代表实际耗时。图算法只考虑上下左右、等权移动；BFS 保证最短路，DFS 不保证。学习代码用于演示，不运行用户输入的任意代码。
